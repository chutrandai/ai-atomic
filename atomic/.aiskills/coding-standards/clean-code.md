# Tiêu chuẩn Code Sạch

- **Dependency Injection**: Luôn sử dụng **Constructor Injection**.
- **Naming**: Đặt tên rõ nghĩa. Tiếng Anh cho code, Javadoc mô tả bằng **Tiếng Việt**.
- **Methods**: Mỗi hàm chỉ làm một việc (Single Responsibility).
- **Error Handling**: Không dùng try-catch bừa bãi. Sử dụng Global Exception Handler.
